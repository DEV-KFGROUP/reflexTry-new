N-Back 是一種持續的工作記憶任務：項目以串流形式出現，當目前的項目與 **N** 步驟之前的項目相符時，你就必須做出反應。這個任務在 2-back 和 3-back 出現之前看似簡單，這時它會迫使你在時間壓力下更新滾動緩衝區。

## N 在實際操作中的意義

- **1-back：** 配對前一個字母。
- **2-back：** 配對兩個試次前的字母。
- **3-back：** 三個試次前——緩衝區很快就會變得擁擠。

Reflextry 的字母 N-Back 是一項**單一串流**任務（非同時包含視覺/聽覺串流的雙重 N-Back）。這讓規則易於學習，同時仍能考驗更新和監控能力。

## 命中、漏失與誤報

高「命中」次數伴隨不斷的誤報並不代表技術好——這只代表反應過度。分數解讀應包含：

- **命中（Hits）：** 在真正的目標出現時正確按下相符（Match）
- **漏失（Misses）：** 出現相符項目卻未做反應
- **誤報（False alarms）：** 根本沒有相符卻按下相符

以訓練出平衡的準確率為目標。許多學習者透過**減少誤報**而非盲目追更高 N，來取得最快的進步。

## 為什麼這項任務很難

每個新字母必須進入工作記憶，同時較舊的字母則會掉出。這種**更新**操作與靜態數字廣度不同，後者是呈現清單後一次回憶。干擾和急躁是導致後半段崩潰的主因。

## 合理的進階計畫

1. 停留在 1-back，直到準確率穩定到覺得有些枯燥。
2. 進入 2-back；記錄兩週的準確率 %。
3. 只有在此之後，才在短時間區塊內嘗試 3-back。
4. 如果準確率暴跌至低於有用的學習區間，請降低 N 值並重新建立基礎。
5. 好勝心作祟（第一天就跳級到 3-back）通常只會教導你如何猜測。

## 有幫助的策略

- 在心中默念最後的 N 個字母，作為滑動視窗。
- 決定得夠晚以辨識字母，夠早以趕上期限。
- 發生誤報後，有意識地重置緩衝區，而不是狂按相符。
- 將訓練時間控制在 10 到 15 分鐘的專注時間內。

## 關於轉移：保持誠實

N-Back 訓練明確能改善 **N-Back** 本身。文獻對於它是否能廣泛提升智力尚有爭議；結果取決於研究設計、對照組以及「遠距轉移」的定義。請將 Reflextry N-Back 視為鍛鍊更新技能的工作記憶健身房——而不是奇蹟般的認知類固醇。

## 搭配其他 Reflextry 工具

- **語文記憶（Verbal memory）**：用於干擾下的熟悉度監控
- **黑猩猩測驗（Chimp test）**：用於視覺空間廣度
- **Flanker / Go-No-Go**：如果你的錯誤源於衝動而非記憶力

不同的瓶頸需要不同的訓練。

## 追蹤進度

記錄 N 等級、準確率 %、命中數，以及你的感覺（睡眠、咖啡因）。在相同的 N 值下，減少誤報與華麗的命中連勝同樣值得慶慶祝。這就是持久的工作記憶控制。

## 心智緩衝區範例（2-back）

假設字母依序出現：A, C, A…
- 在 A 接著 C 之後，你的緩衝區是「A, C」。
- 下一個字母 A 與倒數第二個項目相符 → 相符（Match）。
- 緩衝區變為「C, A」，以此類推。

小聲說出緩衝區可以防止常見的失敗，即你只記得「最近有個 A」，卻不知道它是不是 N 步驟前發生的。

## 何時進行減量週（Deload Week）

如果準確率停滯十天，請將訓練量減半，並將 N 值降低一級，持續一週。工作記憶訓練對睡眠債和壓力非常敏感。減量週通常比更努力硬練更能恢復進度。
